# Portfolio

Personal portfolio website showcasing projects, experience, skills, and professional background.

Built with Astro, TypeScript and GSAP. Deployed to GitHub Pages by `.github/workflows/deploy.yml`
on every push to `main` (repo Settings > Pages > Source: GitHub Actions).

```bash
npm install
npm run dev      # http://localhost:4321/roger.verges-portfolio/
npm run build    # type-check and build to dist/
```

Project content lives in `src/data/projects.ts`; images and recordings in `assets/`.
